# Демо-стенд

Сквозной сценарий кейса на одной странице: график коридора с отметками
срабатываний, клиентский путь от пуша до экрана перевода, механика «момент
изменился», библиотека текстов и матрица соответствия ТЗ.

```bash
open demo/index.html          # ничего собирать не нужно
```

Страница автономна: один HTML, один файл данных, внешних зависимостей нет.
Шрифты подтягиваются с Google Fonts — без сети страница откатывается на
системный гротеск и остаётся читаемой.

## Откуда берутся цифры

`demo/data.js` — выгрузка живого слоя, а не выдумка под макет:

```bash
uv run python demo/export_data.py
```

Скрипт зовёт `signal_layer.signals.signal_table` по `currency_data/` и пишет в
`data.js` ряды курсов, дни, которые коммуникационная политика реально выбрала,
факт каждого пуша, а также аудит на заглядывание вперёд — пересчёт через
`signals_asof` на обрезанной панели и сверку с историческим прогоном.

Сводные метрики бэктеста (81,7 б.п., 5/5 коридоров, p = 0,002) вписаны в
разметку и берутся из `reports/benchmark/leaderboard.csv` — при новом прогоне
бенчмарка их нужно обновить руками.

## Что показывает клиентский путь

Один сигнал по RUB→TJS (котировка от 10.06.2026) и четыре момента открытия
пуша. Экран пересобирается по реальной котировке того дня, а уровень раскрытия
выбирается по величине расхождения:

| Клиент открыл | Δ курса | Что видит |
|---|---:|---|
| через 20 минут | 0 б.п. | плашка «данные актуальны на 10.06.2026» |
| на следующий день | +16 б.п. | плашка со снимком данных пуша |
| спустя несколько дней | +139 б.п. | **модальное окно** «данные были актуальны на …» |
| другое срабатывание, 19.05 → 20.05 | −129 б.п. | плашка: курс ушёл в пользу клиента |

Порог между плашкой и модальным окном — медианное дневное движение самого
коридора (TJS: 53 б.п.): изменение меньше обычного дня не повод прерывать путь.
Раскрытие асимметрично — подтверждение просим только когда курс ушёл против
клиента.

## Оговорки, которые видны на самой странице

Интерфейс — прототип, воспроизводящий структуру публичного приложения, а не его
копия. Получатель и суммы синтетические. Курс ЦБ — не курс исполнения: спред и
комиссия в расчёт не входят.
