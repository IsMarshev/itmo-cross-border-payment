# Фактические сообщения

Текст — детерминированный шаблон, вычисляемый на момент сигнала. Числа берутся из
прошлого/настоящего ряда. Генеративная модель в отправке и принятии решений не участвует.

| Основание | Пример с условными числами |
|---|---|
| Низкий уровень | По данным ЦБ, курс сомони ниже, чем в 85% дней за последние 90 дней. |
| Последовательное снижение | Курс сомони снижался при последних 4 обновлениях ЦБ. |
| Изменение за неделю | Курс сомони по данным ЦБ снизился на 1,80% за неделю. |
| Уже наблюдаемый рост | Курс сомони по данным ЦБ вырос на 0,40% при последнем обновлении. |

При одновременном низком уровне и отскоке внутренний сценарий — window_closing,
а текст сообщает только уже наблюдавшийся рост. Название «окно закрывается»
не показывается клиенту как предсказание. Перенесённые выходные не включаются
в формулировку о серии обновлений. Процент в сообщении округляется вниз, чтобы
не завышать долю исторических дней с более дорогой валютой.

| Не используем | Причина |
|---|---|
| Курс скоро вырастет | Утверждение о неизвестном будущем |
| Успейте, пока не подорожало | Неявный прогноз и давление срочностью |
| Сейчас лучший момент | Непроверяемое превосходство над будущими моментами |
| Гарантируем лучший курс | Нет данных и полномочий гарантировать условия исполнения |
| Вы точно получите больше | Сумма зависит от реальной банковской котировки и времени исполнения |
| Заработайте на курсе | Торговое обещание, не задача перевода денег семье |

Сезонный индикатор использует календарные признаки, но не генерирует фразу
«перед праздником обычно дорожает»: для такого текста необходимо отдельное
достаточное историческое доказательство и проверка отсутствия обещания будущего.
Календарь праздников с `known_on` можно подключить без изменения кода.

Без котировок исполнения в тексте явно назван ЦБ. Итоговые формулировки для
реального пуш-канала согласуются в рамках обычного процесса банка; этот проект
не подменяет его и не выдаёт юридическое заключение.
